# astrbot_plugin_openai_image

基于 OpenAI 兼容图片接口的 AstrBot 图片插件。

当前能力：
- `/oaiimg [数量] [-s 尺寸] [-q 质量] [-m 审核] <提示词>`
- `/oaiedit [数量] [-s 尺寸] [-q 质量] [-m 审核] <提示词>`，支持同一来源内多张输入图
- `/oaiqlogo [数量] [-s 尺寸] [-q 质量] [-m 审核] @用户 <提示词>`
- `/oaifigure`，在同条消息带图或回复图片时设置/更新机器人形象图
- `/oaishow`，展示当前已设置的机器人形象图
- 支持单图独立计时回传（每张图片上方展示真实生成耗时）
- 可在每个图片接口供应商中单独配置 `responses` 或 `images` 端点，`images` 模式支持 `/images/generations` 与 `/images/edits`
- 兼容上游返回 `b64_json` 或 `url` 的图片结果，URL 结果会先下载到本地缓存再发送
- 支持配置默认输出尺寸，也可通过命令参数临时覆盖
- 支持按图片接口供应商单独配置显式代理，内置页面生图和图片编辑同样生效
- 默认仅 Bot 管理员可通过命令参数控制数量、尺寸、质量和审核，可在配置中关闭限制
- 结果缓存到 `data/plugin_data/astrbot_plugin_openai_image/images`
- 提供 WebUI 内置「图片工作台」页面，查看历史图库、预览大图，并在页面内执行生图和图片编辑
- 仅支持通过 OneBot v11 回传 QQ 图片消息
- 提供三个函数工具：
  - `openai_generate_image`
  - `openai_edit_image`
  - `openai_edit_robot_figure_image`

## 命令与参数说明

插件提供了 5 个聊天命令，其中 `/oaiimg`、`/oaiedit` 与 `/oaiqlogo` 支持完整的参数选项。

### 1. 命令概览

| 命令 | 类型 | 说明与输入要求 |
| :--- | :--- | :--- |
| `/oaiimg` | 文生图 | 根据提示词直接生成新图片 |
| `/oaiedit` | 图生图 / 编辑 | 对输入图片进行编辑，需在同条消息附带图片或引用/回复一张图片 |
| `/oaiqlogo` | 头像编辑 | 获取命令中 `@` 用户的 QQ 头像作为输入图执行编辑 |
| `/oaifigure` | 形象图设置 | 将同条消息附带或引用的图片保存为机器人专属形象参考图 |
| `/oaishow` | 形象图查看 | 发送当前已设置的机器人形象参考图 |

### 2. 支持参数详解

在 `/oaiimg`、`/oaiedit`、`/oaiqlogo` 命令中，支持使用以下参数：

#### ① 数量 `[数量]`
- **语法**：命令名称后的**首个正整数**（如 `2`、`3`）。若不指定则默认为 `1`。
- **说明**：批量生成多张图片。当配置项 `multi_image_command_admin_only` 为 `true`（默认值）时，仅 Bot 管理员可生成多张图片，非管理员会被强制重置为 1 张。
- **示例**：`/oaiimg 2 赛博朋克风格的猫咪`

#### ② 尺寸 `-s`, `--size`
- **语法**：`-s <尺寸>`、`--size <尺寸>` 或 `--size=<尺寸>`。未指定时沿用插件配置中的 `image_size`，留空时交给上游模型默认处理。
- **预设别名**：
  | 别名 | 分辨率 | 宽高比与说明 |
  | :--- | :--- | :--- |
  | `auto` | 自动 | 由上游接口决定 |
  | `square` | `1024x1024` | 1:1 正方形 |
  | `portrait` / `vertical` | `1024x1536` | 2:3 经典竖屏 |
  | `landscape` / `wide` | `1536x1024` | 3:2 经典横屏 |
  | `2k-square` | `2048x2048` | 1:1 2K 高清方形 |
  | `2k-portrait` | `1440x2560` | 9:16 2K 高清竖屏 |
  | `2k-landscape` | `2560x1440` | 16:9 2K 高清横屏 |
  | `4k-portrait` | `2160x3840` | 9:16 4K 超清竖屏 |
  | `4k-landscape` | `3840x2160` | 16:9 4K 超清横屏 |
- **自定义尺寸**：
  - 格式为 `<宽>x<高>`（连接符支持 `x`、`X`、`*`、`×`，如 `1280x720`、`1024*1024`）。
  - 限制条件：
    1. 宽和高必须是 16 的倍数；
    2. 单边宽高不能超过 3840；
    3. 长短边比例不能超过 3:1；
    4. 总像素须在 655,360 ~ 8,294,400 之间（约 0.65M ~ 8.3M 像素）。
- **示例**：`-s portrait`、`--size 1280x720`、`--size=square`

#### ③ 质量 `-q`, `--quality`
- **语法**：`-q <质量>`、`--quality <质量>` 或 `--quality=<质量>`。
- **可选值**：
  - `auto`：默认值，自动模式
  - `low`：低画质 / 快速生成
  - `medium`：中等画质
  - `high`：高画质 / 精细渲染
- **示例**：`-q high`、`--quality=medium`

#### ④ 审核级别 `-m`, `--moderation`
- **语法**：`-m <级别>`、`--moderation <级别>` 或 `--moderation=<级别>`。
- **可选值**：
  - `low`：默认值，较低的过滤级别，降低误拦截概率
  - `auto`：模型默认审核策略
- **示例**：`-m auto`、`--moderation=low`

#### ⑤ 提示词 `<提示词>`
- **语法**：去除上述选项后的其余文本内容将全部组合作为提示词。
- **空格与引号处理**：若提示词或参数值含有特殊字符或空格，支持使用单引号 `'...'` 或双引号 `"..."` 进行包裹（基于 Shell 风格解析）。
- **示例**：`/oaiimg 2 -s portrait "a beautiful girl in rain, anime style"`

### 3. 命令使用示例

```text
# 基础文生图
/oaiimg 一只在草地上奔跑的柯基

# 生成 2 张竖版 2K 高清图，质量设为 high
/oaiimg 2 -s 2k-portrait -q high 赛博朋克街头雨夜

# 自定义分辨率文生图
/oaiimg -s 1280x720 雄伟的雪山日落全景

# 图片编辑（需在消息中附带图片或回复图片）
/oaiedit -s square -q medium 改成水彩插画风格

# 使用 QQ 头像进行编辑（需 @ 一位群成员）
/oaiqlogo @某人 -s portrait 改成机甲动漫风格头像
```

### 4. 权限限制说明

- 配置项 `multi_image_command_admin_only`（默认为 `true`）：
  - **开启时**：仅 **AstrBot 管理员**（AstrBot 核心配置中指定的管理员，非 QQ 群管/群主）可以使用多图生成及参数拆解（`-s`、`-q`、`-m` 等）；普通成员发送命令时会被限制为仅生成 1 张，且所有文本均作为提示词传入。
  - **关闭时**：所有成员均可自由使用多图以及完整命令参数。

### 5. 编辑命令提示词预设替换

可在插件配置中设置「编辑命令提示词预设替换」（`edit_prompt_presets`）：
- 支持配置多组触发词（`keyword`）与对应的预设提示词（`preset_prompt`）。
- 当用户在聊天中使用编辑命令（如 `/oaiedit <提示词>`、`/oaiqlogo @用户 <提示词>`）时，若输入的提示词命中了配置中的触发词（忽略首尾空格、标点与英文大小写），将自动替换为对应的预设提示词后再发起图片编辑请求。
- **与提示词优化的配合**：当命中预设提示词时，将直接直通使用预设提示词，**自动跳过大模型提示词优化**，确保预设效果稳定可控且不被二次改写；仅在未命中预设时，普通输入的提示词才会走大模型扩写优化。

### 6. 指令调用提示词优化

可在插件配置中开启「指令提示词优化」（`enable_command_prompt_optimization`）：
- **生效范围**：仅对指令调用生效（`/oaiimg`、`/oaiedit`、`/oaiqlogo` 等），LLM 工具自主生图不受此项影响。
- **工作机制**：开启后，用户输入简要提示词，插件会先调用指定对话大模型将其自动扩写并翻译为纯英文的高质量生图提示词（全为英文，严禁输出中文，包含场景、构图、光影、动作、表情等丰富细节），再提交图像生成与编辑。
- **画面比例规范**：在使用 `/oaiimg` 文生图指令时，优化后的提示词严格包含形如 `1:1`、`16:9`、`9:16`、`4:3` 等数字比例；图片编辑指令（`/oaiedit`、`/oaiqlogo`）保持原图画面比例不受此约束。
- **自定义模型**：可在「指令提示词优化模型」（`command_prompt_optimizer_provider_id`）中自由选取已在 AstrBot 中配置的任意对话大模型提供商（如 OpenAI、Claude、DeepSeek 等）；留空时自动使用 AstrBot 当前默认启用的对话模型。
- **自定义系统提示词**：可在「指令提示词优化系统提示词」（`command_prompt_optimizer_system_prompt`）中输入自定义 System Prompt；留空时自动使用插件内置的高质量纯英文生图提示词优化设定。

## 机器人形象图

使用 `/oaifigure` 设置机器人形象图，使用 `/oaishow` 查看当前已设置的形象图。形象图会保存到 `data/plugin_data/astrbot_plugin_openai_image/figure/robot_figure.png`，重复设置会覆盖旧图。

当 LLM 判断用户想生成机器人自己、Bot 形象、助手形象、看板娘、机器人头像/立绘/表情包等相关图像时，可自动调用 `openai_edit_robot_figure_image`，插件会使用已保存的形象图作为参考图执行图片编辑。

## 图片工作台（WebUI 内置页面）

插件在 `pages/studio/` 下内置一个页面，随插件一起启用，无需任何开关或密码。在 WebUI 的插件页进入「OpenAI 图片生成」插件详情，点击「图片工作台」即可打开，鉴权沿用 AstrBot Dashboard 登录态。

页面包含四个标签页：

- 历史图库：按文件名或提示词搜索、按格式筛选、按时间或名称排序、分页浏览，点击缩略图可在右侧查看大图和提示词等元数据，并支持删除原图和查看原图
- 生图：在页面内提交文生图任务，可设置数量、尺寸、质量和审核级别，支持调用配置好的文本模型优化提示词
- 编辑：上传或直接粘贴多张参考图，提交图片编辑任务
- 设置：配置提示词优化使用的 OpenAI 兼容 Chat Completions 模型

几点说明：

- 页面运行在 Dashboard 的受限 iframe 中，图片由插件后端以 base64 内联返回，列表使用服务端生成的 webp 缩略图并缓存在 `data/plugin_data/astrbot_plugin_openai_image/webui_thumbnails`
- 页面亮暗主题跟随 WebUI 的主题设置
- 「设置」标签页的提示词优化配置保存在 `data/plugin_data/astrbot_plugin_openai_image/prompt_optimizer_settings.json`；图片供应商、默认尺寸、并发等其余参数仍在插件设置页调整
- 新增或删除 `pages/` 下的页面目录后需要重载插件才会生效

## 图片接口代理

可在每个图片接口供应商中单独设置 `model`、`endpoint_type` 和 `proxy_url`，例如 `http://127.0.0.1:7890`。其中 `model` 与 `endpoint_type` 只对当前供应商生效；`proxy_url` 只在当前启用供应商请求 OpenAI 兼容图片接口并读取响应时使用，因此命令、LLM 工具和图片工作台的文生图/图片编辑都会走该供应商的代理；图库读取、图片回传和提示词优化接口不会受该配置影响。
